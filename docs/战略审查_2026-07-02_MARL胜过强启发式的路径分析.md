# 战略审查报告：MARL 能否胜过强启发式，以及有效路径

**日期**：2026-07-02。**提问**（owner）：审查项目改进记录与现状，分析能否实现"基于 MARL 的多目标优化 V2X 组网最优化端到端模型，在仿真环境中胜过基线模型或强启发式模型"；如果可以，有效的修改路径是什么。

**方法**：5 智能体审查工作流（3 个证据挖掘 + 1 个对抗性批评 + 综合；77 次工具调用），所有结论对照仓库文档 / 代码 / JSON 工件核实（run `wf_438a1fab-e5f`）。所有引用带文件来源；"记忆中的数字"与"仓库工件"严格区分。

---

## 一、直接判定

**有条件的"能"（QUALIFIED YES）——但不在当前任务配置上，且不在直觉以为的"规模化"路径上。**

1. 在**当前配置**（N≤16 + 被动 stale 观测 + 单帧可行性主导）下，"胜过 local_hysteresis"已被六个对抗验证的战役证明**在信息层面不可达**——连中央 evaluator-greedy（决策时无限算力 + 全局信息）都只能不显著地略胜 anchor（urban 0.793–0.800 vs 0.739，配对 CI 跨 0；Q12/D13）。这不是模型学习能力问题，是这个任务里**没有可学的差距**。
2. **全仓库唯一 CI-positive、多种子复现的空间只有一个：信息差距**——true-CSI vs stale-CSI 可行性 +0.09~0.15（5/5 种子，DF2 oracle_regate_metrics.json）；oracle 转化配对 +0.131，p=0.0022（DF3）。且 DF 战役证明这个信息**预测不出来**（决策关键边上方向精度 0.40 < 随机，df3d）。
3. **因此有效路径 = 主动探测（active probing）**：不再预测缺失的 CSI，而是把"这一帧测哪几条边"变成策略动作，在硬探测预算下**获取**它。这是启发式从未持有过的杠杆；规范文档 S4.3 早已预见（"per-node probing budget"、"local top-uncertainty probing"）但从未实现——目前的探测掩码是冻结的 SHA-256 种子计划（csi_observation_model.py），不是动作。

## 二、证据审查中的关键修正（先纠正三个流传的错误认知）

**修正 1（最重要）："N=24 击败 oracle +0.177"已经退役，不能引用。**
- 那个结果击败的是**集中式 SA 搜索**（静态单步组装任务的搜索型 teacher，stage31_scenario_generator.py:482），**不是** local_hysteresis——不同任务、不同基线。
- 它是在 2026-06-23 环境数学修正**之前**的旧 'op' 数据上算的，已被明确标记 `retired_due_to_protocol_metric_change`（CURRENT_HEAD_STATUS.md:420）。修正协议下的 in-range 复跑 = 与 SA 统计平手（−0.031 CI[−0.086,+0.024]；采样修复后 −0.045 [−0.083,−0.006]）；**修正后的 N=24 对比从未重跑**（被 O(n⁴) 精确 fault 评估器成本卡住）。
- "5 种子 CI [+0.104,+0.249]"只存在于自动记忆里；研究日志止步于 n=4（+0.173 [+0.067,+0.279]）。按"记忆 ≠ 仓库证据"处理。

**修正 2：P1（规模化）的前提是零数据的猜想，且先验指向反方向。**
local_hysteresis 在 N>16 上**从未被评估过**（六个战役全部 N∈{8,12,16}，CURRENT_HEAD_STATUS.md:68,80）。已测到的 N≥24 崩溃恰恰是**学习臂**的（静态 frozen/BC actor 在 N=24/32/48 上 0.00 vs SA ~0.60）——在规模上先崩的是学习方，不是启发式。anchor 是每节点 30 行的 top-k，没有任何计算上崩溃的理由。

**修正 3：能耗 Pareto 点也不存在。**
β=0.3 "−14% 能耗"是单种子；多种子配对结果 −4.5% CI [−15.5%, +6.5%] 跨 0，已作为 NULL 回滚。ω-conditioned Pareto front 只有脚手架（DynamicPNAActor.set_preference），从未扫过。**项目目前没有任何已证明的能耗交换。** 另外：动态回报 J 目前是"时延盲"的——reward_of 算出 `_lat` 又丢弃，reconfig_l=0。

## 三、"锚定复制 / 放松漂移"不是模型能力缺陷——它已经被解决过一次

这个困境在去中心化 RL trunk（train_decentralized_rl.py）里被根因定位并修复过：停滞原因是**零探索**（温度方向反了 + Plackett-Luce 采样器在预算处确定性 + gate 下的边不可探索）和**奖励信号饥饿**（二元 barrier）。修复配方——**高斯动作空间探索（在 gate 边界上探索）+ 稠密势函数奖励 (c−τ) + RLOO 基线 + 拉格朗日对偶 + 只在可解场景训练**——让模型从随机初始化、无 oracle 冷启动，真实学到 held 0.688/0.909（≈ teacher 天花板）。这套配方是现成资产。

**结论性的理解**：当存在可学差距时，这套机器能学（trunk-B in-range、R5 rankable 都证明过）；六个战役全部撞墙不是因为机器坏了，而是因为 anchor 已经坐在该任务配置的信息约束最优上。**你无法在天花板上方学习——必须换一个天花板更高的问题。**

## 四、四条候选路径的对抗性裁决

| 路径 | P(真差距) | 最可能的失败 | 公平基线要求（防稻草人） | 首个 kill-test |
|---|---|---|---|---|
| **P2 主动探测** | **中**（系统级）/ 中低（严格 MARL 级） | margin+age-greedy 启发式探测器已捕获大部分 headroom → 学习 vs 启发式探测器 CI 跨 0 | anchor 必须配上**最强固定探测器**（random / round-robin / age-greedy / **margin+age-greedy**），同一硬预算；只对比 random 是稻草人 | **eval-only、零训练、数天**：千里眼分配 vs 贪心分配 vs 随机，喂同一 anchor（S1 双门） |
| P1 规模化动态任务 | 低 | 双重挤压：学习方先崩（学习悬崖）+ 近似 fault 评估器噪声吞掉小差距 | local_hysteresis **实测**于 N=24/32/48（阈值按 N 重调）+ 同 N 中央 greedy 天花板；两侧同一近似评估协议、对小 N 精确枚举 pinned | 零训练：N=24 动态集只跑零训练臂；**anchor 不退化或 central−anchor 差距不打开 → P1 永久死亡** |
| P3 多目标 Pareto | 低（对公平基线） | weighted-anchor（psucc − w·E − v·L 同样 top-k + hysteresis）可平凡构造 → 胜过纯 psucc anchor 是近稻草人 | **必须构造并调优 weighted-anchor 启发式 front**（5×5 (w,v) 网格，零 eval 调用）；先把时延项加入目标（两侧同时） | 零训练：中央标量化 greedy front 若不能 CI-支配调优启发式 front → 学习版更不可能，P3 死 |
| P4 时序规划 | 最低 | Δ_H = max(0, 2r−H)——价值是**配置制造的**（调高 reconfig 成本 / 缩短 hold 就"造出"机制生效的场景）；21% 尾部场景的识别撞同一堵信息墙 | 同等 reconfig 成本下**扫过 keep-threshold 的 anchor**（hysteresis 本身就是 1 参数时序机制）+ 千里眼 DP 天花板 | 两天诊断（复用 dynamic_temporal_value.py），预期双杀，从路线图永久移除 |

**批评者最重要的洞察**：全项目唯一 CI-positive 的空间是信息差距，其它每个候选差距都建立在退役数字、CI-零先验或配置制造的机制上。理性的行动是 P2——**停止预测缺失信息（已证明低于随机），转而获取它**。但诚实的标准不是"探测胜过不探测"，而是"**学习的探测分配器胜过同预算下的 margin+age-greedy 启发式探测器**"——这个问题在任何训练之前、用几天的纯评估计算就能判定（测量 oracle 分配器 vs 启发式分配器的差距）。如果贪心分配已捕获 headroom，正确的交付物是启发式系统升级，而不是第七个 MARL 战役。

**探测目标信号是 leak-free 且今天就可计算的**：~29% 的边是预算边缘边（df3c mean_slot_fraction 0.2945）；观测年龄已是 actor 输入；DF2 证明新鲜测量的决策价值恰恰在低自相关处最大（低 ρ 时几何侧优势 +0.044）。

## 五、推荐执行程序（cheapest-kill-first，每阶段带 GATE）

- **S1 — P2 kill-test**（eval-only，N≤16，零训练，~数天）：实现两个缺失原语——(a) 有状态的逐边 (last_observed_value, age) 观测缓冲（替换冻结的种子计划），(b) 硬性每节点探测预算解码器（复用现有 budget/top-k 机制）。三个分配器喂**同一个** anchor，跨 d_corr 旋钮的 ρ 扫描：(i) 千里眼 oracle 分配（探测那些"刷新后会把 anchor 决策翻向 true-CSI 动作"的边）、(ii) margin+age-greedy、(iii) random。
  - **GATE A**：硬预算探测在真实 ρ、图级 feasibility 指标上相对不探测 CI-positive（把 DF2 的理想化持久链路 headroom 转化到真实指标——目前未验证）。
  - **GATE B**：oracle 分配 − 贪心分配的差距 CI>0——**这个差距就是学习探测器的全部生存空间**。
  - A 败 → P2 死；A 过 B 败 → 交付物改为"anchor + 启发式探测器"系统升级（预注册 fallback）。
- **S2 — P3 公平性预门**（零训练，与 S1 并行）：把时延项加入目标（两侧同时），构造 weighted-anchor front + 中央标量化 greedy front。**GATE**：中央天花板在可部署区域（feasibility ≈ anchor 水平）CI-支配调优启发式 front；否则 P3 在训练前死亡。
- **S3 — P2 训练战役**（仅当 GATE B 通过）：~4 文件 + 1 模块接线（actor 上并行的逐边探测头 + 硬 top-k 探测解码器 + rollout 掩码线程），用 trunk-B 已验证配方训练（稠密势奖励 + RLOO + 拉格朗日 + gauss 探索）。**headline bar 训练前冻结进契约：learned prober vs margin+age-greedy prober，同预算同缓冲**——不是 vs random，不是 vs 不探测。5 种子 × {urban, random}。
- **S4 — P2+P3 合并**（仅当 S1-A 与 S2 都过）：探测预算成为显式目标轴，激活 ω-conditioned 偏好脚手架（ω ~ (可靠性, 能耗, 时延, 探测/切换成本) 单纯形，一个网络 ≥5 个 ω 点），front-vs-front 对比"最强可构造启发式系统"（weighted-anchor + 最佳探测器，配对，5 种子，hypervolume + 至少一个可部署角点配对 CI>0）。**这是 headline——"MARL 多目标模型胜过最强可部署启发式系统"——真正可能诞生的地方。**
- **S5 — P1 作为规模化探针**（零训练先行；仅当已有 S3/S4 胜果需要规模化时投入）：先造 pinned 的近似 fixed-set fault 评估器（精确版 O(n⁴)，N=24/f=7 = 34.6 万组合不可行；近似器需在小 N 对精确枚举 pinned、两侧同协议），N=24 动态集（vectorized float-identical 评估器 + jobs≤2）只评零训练臂。**双条件门**：anchor 实测退化 **且** central−anchor 差距 CI-positive 打开——两条都成立才训练任何学习臂。
- **S6 — P4 诊断性埋葬**（2 天，可选，最低优先级）：honest 配置下扫 hysteresis 阈值 + 尾部场景可识别性 AUC；预期双杀，文档化后从路线图永久移除。

## 六、声明纪律（避免第七个诚实负面 + 审稿人杀手）

现在就决定 headline 层级并**预注册**：
- **主声明**（严格 MARL 级）：学习的探测+拓扑联合策略在同一硬预算下胜过最强启发式探测系统。
- **预注册 fallback**（系统级，概率高得多，也是真实的工程贡献）：探测系统（anchor + 启发式探测器）CI-positive 地胜过现部署系统。

事后把 fallback 包装成主声明正是 4090-audit 里被抓的模式——提前冻结即可免疫。

**不要做的**：在 N≤16 被动观测配置上再换任何目标/结构/激活/环境自相关（六重证明已死）；引用 +0.177 做任何论证（已退役）；对未调优的 psucc-only anchor 做 Pareto 对比（稻草人）；在 kill-test 之前投入任何训练战役。

## 七、一句话总结

六个战役证明的是"这个任务配置没有可学差距"而非"模型学不会"（学习配方已在去中心化 RL trunk 验证过：gauss 探索 + 稠密势奖励 + RLOO + 拉格朗日）；全仓库唯一真实的空间是**信息差距**（true−stale +0.09~0.15，5/5 种子；oracle +0.131 p=0.0022，而预测已证明低于随机），攻击它的唯一未持有杠杆是**把感知变成动作（主动探测）**——先用几天的零训练双门 kill-test（S1：GATE A 探测是否转化 / GATE B 学习分配是否有生存空间）判定这条路是否存在，再决定投入训练；P3 多目标作为并行预门（weighted-anchor 公平 front），P1 规模化降级为零训练探针，P4 时序规划诊断性埋葬。
